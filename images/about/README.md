# Family Moneyについてセクション用画像

このフォルダに以下のファイルを置くと、HPの「Family Moneyについて」の4つの枠に表示されます。

- **about_1.jpg** … 1枚目（左）
- **about_2.jpg** … 2枚目
- **about_3.jpg** … 3枚目
- **about_4.jpg** … 4枚目（右）

## 推奨

- 形式: JPG または PNG
- 縦横比: 正方形（1:1）だとレイアウトが崩れません（横長・縦長でも `object-fit: cover` でトリミング表示されます）
- サイズ: 1辺 400px 前後で十分です

画像を置かない場合は「イメージ画像1」などのプレースホルダーが表示されます。
